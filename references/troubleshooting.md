# 常见失败 → 原因排查 → 只改一个变量

| 失败表现 | 优先核实 | 最小重测动作 |
|---|---|---|
| 文生图笼统、构图随机 | 输入仅短词/关键词 | 先用PUP变成full scene caption；固定Seed重测 |
| PUP ON结果改变主旨 | 扩写后的最终caption漂移 | 读取并锁定扩写结果，修正文案后OFF重测 |
| 改耳饰但脸变了 | 用了单句编辑、框太大、编辑本身是重建 | 补全结果caption、缩小框、保存原图对照 |
| `dress`没有变红 | `desc`只写dress，但主提示词没有to red | 主caption明确目标颜色和原图服装保持项 |
| 红花长在脸颊而非耳朵 | 框中心或范围不准、耳饰太小 | 调整框定位，适当增大可识别区域，重测 |
| 框选完全没影响输出 | Flux3LayoutPrompt输出没连接实际CLIP编码 | 检查最终连接、查看PreviewAny输出与编码器输入 |
| `<obj_2>` 不起作用 | 框选编辑器只有obj_1或ID不一致 | 对齐ID及desc，检查自动附加JSON |
| 多图混脸/串衣服 | 参考图位置角色不明、遮挡/来源冲突 | 明确各图职责，固定顺序，先2图再3/4图 |
| 文本变拼写错误 | 模型固有限制、字太小/过复杂 | 减少文本行数、逐字双引号、增大文本区域并评分 |
| Base和Distilled的画面差太大 | 两支实际输入caption不同、分辨率裁剪不同、种子/参数不一致 | 导出最终caption及参数、逐项对齐后复测 |
| 负面提示词不起作用 | Distilled可能不使用负条件；接线不同 | 核查节点连接和CFG；用正向完整描述做主约束 |
| 身体手指异常 | 全身人物太小或动作用语模糊 | 指定镜头完整包含手脚、手持物件及朝向，适当提高主体占比 |

风险定义：`prompt adherence`（描述遵循）、`composition adherence`（构图遵循）、`identity consistency`（身份一致）、`local preservation`（局部保留），分别打分，不合并成一个主观总分。
